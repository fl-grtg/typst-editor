# Code of Conduct

We want this project to be a welcoming place for everyone, regardless of experience, background or identity.

## Our standards

Expected:

- Be respectful and assume good intent.
- Give and accept constructive feedback; criticise ideas, not people.
- Keep discussions on topic and use clear, inclusive language.

Not acceptable:

- Harassment, insults, discrimination or personal attacks.
- Publishing others' private information.
- Sustained disruption of discussions or pull requests.

## Enforcement

Maintainers may edit, hide or remove contributions that violate this code and may temporarily or permanently
ban contributors for behaviour they consider inappropriate.

Report problems privately through GitHub (a private security advisory or a direct message to a maintainer).
All reports are handled confidentially.

This text is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
